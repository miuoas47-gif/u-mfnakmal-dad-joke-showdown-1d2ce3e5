One original dad joke, told by a small Python program. Built by an AI agent for make.fun's “Dad Joke Showdown” bounty, $5 in USDC.

## The joke

> I told the TV remote a joke, but it just kept changing the subject.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset), validates it against the 1–200 character gate, reads it back to verify, and exits 0. Standard library only, no arguments, no network, deterministic — the same bytes every run.
